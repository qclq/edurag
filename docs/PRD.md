## 1. 文档说明

### 1.1 编写目的

本文档用于定义校园知识库问答系统的前端产品范围、目标用户、角色权限、页面结构、核心业务流程、交互状态、响应式要求和验收标准，为后续原型设计、UI 设计、前后端接口设计、开发和测试提供统一依据。

### 1.2 产品定义

校园知识库问答系统是面向校内师生及管理人员的知识检索与智能问答平台。管理员将学校发布的规章制度、通知公告、办事指南、教学资料等文档上传到系统，系统在服务端完成文件解析、文本切分、向量化和知识库入库。普通用户通过自然语言提问，系统检索其有权访问的知识库内容，结合大模型生成答案，并提供可追溯的引用来源。

### 1.3 需求边界

本文档主要描述前端能够感知和操作的产品能力，不规定大模型、Embedding 模型、向量数据库、文档解析器等后端技术实现。

首期产品不以开放式通用聊天为目标。系统回答应优先基于校内知识库内容，不应将无来源的模型常识伪装成校方正式答复。

## 2. 项目背景与问题

学校内部通常存在大量制度文件、通知、指南和业务材料，分散在门户网站、公众号、网盘、各部门网页或本地文件中。师生在处理学籍、课程、奖助学金、住宿、校园卡等事务时，常面临以下问题：

- 文档入口分散，难以快速找到权威版本。
- 文件篇幅较长，用户难以定位具体条款。
- 不同部门的内容命名和组织方式不统一。
- 同一问题被重复咨询，管理部门答疑成本较高。
- 文件更新后，旧版本内容仍可能被继续传播。
- 普通大模型可能产生不符合校方规定的回答，且缺少可靠出处。

本系统通过统一的知识库管理和基于引用的智能问答，降低信息获取成本，同时为管理员提供内容维护、用户管理、问题分析和质量改进能力。

## 3. 产品目标与成功标准

### 3.1 产品目标

1. 帮助师生通过自然语言快速获得校园事务相关答案。
2. 确保答案尽可能基于有效、可访问、可追溯的校方文档。
3. 建立从文档上传到知识入库的透明处理流程。
4. 支持管理员维护知识库、文档、用户及权限。
5. 通过问答记录、负面反馈和未命中问题持续发现知识缺口。

### 3.2 首期成功标准

- 用户可以完成“登录—提问—查看回答—查看引用原文—继续追问”的完整流程。
- 有知识库依据的答案能够展示至少一个可访问的引用来源。
- 无可靠依据时，系统明确表达未找到答案，不编造文档或条款。
- 管理员可以完成“上传文件—填写信息—查看处理进度—处理失败任务—确认入库”的完整流程。
- 管理员可以创建、查询、编辑、启用和停用用户账号。
- 普通用户端的核心问答流程可在手机端正常使用。
- 所有核心页面均具有加载、空、错误和无权限状态。

### 3.3 建议关注的产品指标

| 指标 | 说明 |
| --- | --- |
| 问答成功率 | 正常完成并返回结果的问答次数占比 |
| 有效引用率 | 返回答案中包含有效引用的问答占比 |
| 无答案率 | 系统未检索到足够依据的问答占比 |
| 用户满意率 | 点赞次数占已反馈回答次数的比例 |
| 首次响应时间 | 用户发送问题到页面出现首个响应状态的时间 |
| 完整回答时间 | 用户发送问题到回答与引用全部完成的时间 |
| 文档入库成功率 | 成功完成解析和向量化的文档占比 |
| 知识更新时效 | 文档上传至可被正常检索的平均耗时 |
| 高频未命中问题数 | 指定周期内重复出现且无法回答的问题数量 |

## 4. 名词解释

| 名词 | 定义 |
| --- | --- |
| 知识库 | 按主题、部门或业务范围组织的一组可检索文档与知识切片 |
| 文档 | 管理员上传的原始文件及其元数据 |
| 文档解析 | 从 PDF、Word 等文件中提取文本、标题、页码等信息的过程 |
| OCR | 对扫描件或图片中的文字进行识别的过程 |
| 切片 | 为检索而从文档中拆分出的文本片段 |
| 向量化 | 将文本片段转换为可进行语义检索的向量数据 |
| 入库 | 文档处理完成并可被问答检索使用的状态 |
| RAG | 先从知识库检索相关内容，再由大模型结合检索结果生成答案的方式 |
| 引用来源 | 支撑回答内容的文档、页码、章节和原文片段 |
| 会话 | 用户围绕某个主题进行的一组连续问答 |
| 未命中 | 未检索到足够相关或足够可信的知识库内容 |
| 重建索引 | 重新执行知识切分或向量化，使知识库检索数据更新 |

## 5. 目标用户

### 5.1 学生用户

主要诉求：

- 查询学籍、选课、考试、成绩、奖助学金、宿舍、校园卡、图书馆等信息。
- 快速获得办事条件、所需材料、办理地点和截止时间。
- 查看答案对应的正式文件和原文，确认信息可靠性。
- 保存或重新查找历史对话。

使用特点：

- 高频使用手机。
- 问题表达口语化，可能缺少标准业务名词。
- 对结果速度敏感，但对涉及资格、金额、日期等内容也要求准确。

### 5.2 教职工用户

主要诉求：

- 查询教学管理、人事制度、科研管理、财务报销等规定。
- 快速定位制度条款和文件版本。
- 在连续追问中进一步确认例外情况或具体流程。

使用特点：

- 桌面端和移动端并用。
- 更关注文件发布时间、生效状态、发布部门和原文上下文。

### 5.3 知识库管理员

主要诉求：

- 创建和维护特定业务范围的知识库。
- 上传、分类、更新和停用文档。
- 查看解析与向量化状态，处理失败任务。
- 测试知识检索效果，发现内容缺失或版本问题。

### 5.4 用户管理员

主要诉求：

- 创建、导入、查询和编辑用户。
- 调整用户角色、院系和账号状态。
- 重置密码，查看必要的账号操作记录。

### 5.5 超级管理员

主要诉求：

- 管理全局知识库、文档、用户和权限。
- 查看系统运行概况、审计日志和服务配置状态。
- 配置全局规则和管理员权限。

## 6. 角色与权限

### 6.1 角色定义

首期建议设置以下角色：

1. 普通用户：使用问答、查看本人历史记录和个人资料。
2. 知识库管理员：管理被授权的知识库及其中的文档，查看相关问答分析。
3. 用户管理员：管理普通用户账号，不默认拥有知识库配置权限。
4. 超级管理员：拥有全局管理权限，可分配管理员角色。

同一账号可以拥有多个管理角色。管理员同时具备普通用户问答能力。

### 6.2 权限矩阵

| 功能 | 普通用户 | 知识库管理员 | 用户管理员 | 超级管理员 |
| --- | --- | --- | --- | --- |
| 使用智能问答 | 是 | 是 | 是 | 是 |
| 查看本人历史会话 | 是 | 是 | 是 | 是 |
| 查看引用文档 | 仅限有权限内容 | 仅限有权限内容 | 仅限有权限内容 | 全部 |
| 创建知识库 | 否 | 按授权 | 否 | 是 |
| 编辑知识库 | 否 | 按授权 | 否 | 是 |
| 上传与维护文档 | 否 | 按授权 | 否 | 是 |
| 测试知识检索 | 否 | 按授权 | 否 | 是 |
| 查看问答记录 | 仅本人 | 授权知识库范围 | 按隐私策略 | 全部 |
| 处理用户反馈 | 否 | 授权知识库范围 | 否 | 全部 |
| 管理普通用户 | 否 | 否 | 是 | 是 |
| 分配管理员角色 | 否 | 否 | 否 | 是 |
| 修改系统设置 | 否 | 否 | 否 | 是 |
| 查看审计日志 | 否 | 仅本人相关操作 | 按授权 | 全部 |

### 6.3 权限原则

- 前端只负责展示和交互限制，所有权限必须由后端再次校验。
- 用户无权访问的知识库内容不得出现在检索结果、引用摘要、搜索建议或统计数据中。
- 文档预览权限与文档下载权限可以独立配置。
- 管理员查看用户问答内容应受到权限控制，并记录审计日志。
- 修改角色、批量禁用用户、删除知识库等高风险操作必须二次确认。

## 7. 产品范围

### 7.1 MVP 范围

- 登录、退出和角色路由。
- 普通用户智能问答。
- 流式回答、停止生成、重新生成。
- 引用来源展示与原文定位。
- 多轮对话和历史会话管理。
- 知识库新增、编辑、启用、停用和详情查看。
- 文档上传、元数据填写、处理进度、失败重试和详情查看。
- 用户查询、新增、编辑、启用、禁用和重置密码。
- 基础问答记录、反馈管理和统计概览。
- 系统级加载、空、错误、无权限和网络异常状态。
- 普通用户端移动适配，管理端基础响应式适配。

### 7.2 后续版本候选范围

- 对话分享与导出。
- 语音输入与语音播报。
- 普通用户上传临时附件进行问答。
- 图片、复杂表格和公式的增强解析。
- 知识库定时同步学校网站或外部数据源。
- 文档版本自动比对和过期提醒。
- 多模型选择及模型效果对比。
- 知识库质量评测和自动化测试集。
- 知识图谱与关联推荐。
- 更细粒度的数据权限和审批流程。
- 多语言问答。

### 7.3 首期不做

- 不提供无限制的开放域闲聊能力。
- 不允许普通用户直接修改知识库内容。
- 不在前端暴露模型密钥、数据库地址等敏感配置。
- 不默认允许管理员绕过权限查看全部个人隐私内容。
- 不将“文件上传成功”等同于“知识已经可问答”。

## 9. 全局框架与导航

### 9.1 普通用户端导航

桌面端建议包含：

- 顶部品牌区：系统名称、学校标识。
- 左侧会话区：新建对话、搜索历史、会话列表。
- 主内容区：欢迎页或对话内容。
- 用户菜单：个人中心、使用帮助、进入管理后台（有权限时）、退出登录。

移动端规则：

- 左侧会话区收纳为抽屉。
- 顶部保留新建对话、会话标题和用户菜单入口。
- 输入区域固定在页面底部，并适配软键盘和安全区域。

### 9.2 管理后台导航

一级导航建议包括：

- 管理概览
- 知识库管理
- 文档管理
- 任务中心
- 用户管理
- 问答与反馈
- 系统设置
- 操作日志

导航项根据角色权限动态展示。用户通过直接地址访问无权限页面时，必须进入无权限页，不得只显示空白内容。

### 9.3 管理端公共页面结构

- 页面标题与说明。
- 面包屑导航。
- 主操作按钮。
- 搜索与筛选区域。
- 内容区域。
- 分页或连续加载区域。
- 批量操作条。
- 反馈提示、确认弹窗或任务状态入口。

## 10. 核心业务流程

### 10.1 用户问答流程

1. 用户登录系统。
2. 系统加载用户有权访问的知识库范围。
3. 用户输入问题，可选择允许访问的知识库；未开放选择时由系统自动确定范围。
4. 前端校验内容是否为空、是否超过长度限制、是否存在正在提交的重复请求。
5. 页面立即显示用户消息，并进入“理解问题/检索知识库”状态。
6. 后端返回检索与生成状态，前端逐步展示状态文本。
7. 大模型开始流式返回答案，前端实时渲染。
8. 生成结束后，系统返回引用来源、相关问题和回答状态。
9. 用户可以查看引用、复制回答、点赞、点踩、重新生成或继续追问。
10. 当前对话自动保存，并生成或更新会话标题。

### 10.2 无可靠答案流程

当检索结果为空或相关性不足时：

1. 页面明确提示“未在当前可访问的知识库中找到足够依据”。
2. 不展示虚构的引用来源。
3. 可以提示用户补充关键条件或换一种方式描述问题。
4. 可以展示与问题相关的知识库分类或推荐问题。
5. 提供“反馈给管理员”入口，并记录原问题、检索范围和未命中状态。

### 10.3 文档入库流程

1. 管理员进入上传文档页面。
2. 选择或拖拽一个或多个文件。
3. 前端校验文件格式、大小、数量和重复情况。
4. 管理员选择知识库，并填写分类、发布部门、发布日期、可见范围等信息。
5. 管理员确认上传，前端显示各文件上传进度。
6. 上传完成后，文件进入等待处理状态。
7. 系统依次执行解析、OCR（需要时）、文本切分、向量化和入库。
8. 前端通过任务中心或文档详情展示阶段状态与处理结果。
9. 处理成功后文档变为“已入库”，可以被问答检索。
10. 处理失败时展示失败阶段、原因、建议和重新处理入口。

### 10.4 文档更新流程

建议首期将更新后的文件作为新版本处理：

1. 管理员在文档详情中选择“上传新版本”。
2. 系统保留原版本记录，并标记新旧版本关系。
3. 新版本完成入库前，旧版本是否继续可用由管理员选择。
4. 新版本成功入库后，可自动停用旧版本或由管理员确认切换。
5. 切换过程应避免同一制度的冲突版本同时参与检索。

如首期暂不实现版本管理，则“替换文件”必须明确提示会重新解析和向量化，并说明处理期间的可用性。

### 10.5 用户管理流程

1. 管理员通过搜索、筛选或批量导入找到目标用户。
2. 查看用户基本信息和账号状态。
3. 执行编辑、角色调整、启用、禁用或重置密码。
4. 高风险操作展示影响范围和二次确认。
5. 操作完成后更新列表，并记录操作者、时间、对象和结果。

### 10.6 反馈闭环流程

1. 用户对回答点赞或点踩。
2. 点踩时选择原因，可补充文字说明。
3. 系统创建反馈记录并关联问题、回答、引用、知识库和用户。
4. 管理员查看并分类处理。
5. 管理员填写处理结论，例如补充文档、更新旧文档或确认回答无误。
6. 反馈变为已解决，并保留处理记录。

## 11. 公共页面详细需求

### 11.1 P01 登录页

#### 页面目标

完成身份认证，并根据账号角色进入问答端或管理后台。

#### 页面模块

- 学校标识与系统名称。
- 系统简短说明。
- 登录账号输入框。
- 密码输入框，支持显示/隐藏密码。
- 验证码区域（若安全策略要求）。
- 记住登录状态。
- 登录按钮。
- 忘记密码入口。
- 学校统一身份认证入口（若接入）。
- 隐私政策、使用条款和系统支持信息。

#### 交互规则

- 账号和密码为空时，在对应字段下方提示，不提交请求。
- 登录过程中按钮进入加载状态，避免重复提交。
- 登录成功后，普通用户进入问答首页；仅有管理权限或上次停留在管理端的用户可进入管理后台。
- 同时拥有普通和管理权限的用户，可在两个端之间切换。
- 登录失败时区分账号或密码错误、账号被禁用、验证码错误、服务异常等情况。
- 若会话失效导致重新登录，登录成功后优先返回原访问页面；无权限时回到默认首页。

#### 页面状态

- 默认状态。
- 字段校验错误。
- 登录中。
- 登录失败。
- 账号已禁用。
- 统一认证不可用。
- 系统维护中。

### 11.2 P02 忘记密码页

- 若使用本地账号，支持通过预留手机号或邮箱发起找回流程。
- 若账号由学校统一认证管理，明确提示前往统一认证平台处理。
- 不通过错误提示泄露某个账号是否真实存在。
- 提交后展示下一步说明和重新发送倒计时。

### 11.3 P03 无权限页

- 明确说明当前账号无权访问该页面或资源。
- 提供返回首页按钮。
- 管理员可见时提供联系超级管理员的说明。
- 不展示受限资源的标题、摘要或其他敏感信息。

### 11.4 P04/P05 异常页面

- 页面不存在：提供返回首页、返回上一页。
- 服务异常：说明当前无法使用，提供重试和问题反馈入口。
- 应保留全局导航或清晰的返回路径，避免用户陷入死路。

## 12. 普通用户端详细需求

### 12.1 U01 问答首页

#### 页面目标

帮助用户快速理解系统能力并发起第一次提问。

#### 页面模块

1. 欢迎区
   - 问候语。
   - 系统能力说明。
   - 使用边界与权威性提示。
   - 当前可访问知识范围的简要说明。
2. 推荐场景
   - 教务与课程。
   - 学籍与毕业。
   - 奖助学金。
   - 宿舍与后勤。
   - 校园卡与网络。
   - 图书馆。
   - 校园安全。
3. 推荐问题
   - 由运营配置或根据热门问题生成。
   - 点击后将问题填入输入框或直接发送，具体行为保持全站一致。
4. 提问输入区
   - 多行文本输入框。
   - 发送按钮。
   - 知识库选择器（仅在产品开放时展示）。
   - 字数提示。
   - 使用说明入口。

#### 功能规则

- 默认输入框自动聚焦仅适用于桌面端；移动端避免自动弹起键盘。
- 输入内容仅为空格时不可提交。
- Enter 发送、Shift+Enter 换行；移动端使用显式发送按钮。
- 达到字数上限后不允许继续输入，并给出明确提示。
- 不允许在同一会话中并发提交多个问题。
- 如用户没有任何可访问知识库，展示无权限或未配置状态，不展示可用输入框。

#### 空状态文案方向

- 标题：可以询问学校制度、办事流程和校园服务。
- 辅助说明：回答将优先依据学校知识库，并标注引用来源。
- 风险提示：重要事项请以学校最新正式通知为准。

### 12.2 U02 对话详情页

#### 页面目标

支持多轮问答，并以可验证、易阅读的方式展示回答和引用来源。

#### 页面模块

1. 会话头部
   - 会话标题。
   - 当前知识库范围。
   - 重命名入口。
   - 删除会话入口。
2. 消息列表
   - 用户消息卡片。
   - AI 回答内容。
   - 生成阶段状态。
   - 错误或中断状态。
3. 回答操作区
   - 复制答案。
   - 点赞。
   - 点踩。
   - 重新生成。
   - 查看引用。
4. 引用来源区
   - 引用编号。
   - 文档名称。
   - 发布部门。
   - 发布时间或生效日期。
   - 页码、章节或段落位置。
   - 原文摘要。
   - 查看原文。
5. 相关问题区
   - 根据当前回答给出 2 至 4 个建议追问。
6. 底部输入区
   - 多行输入。
   - 发送/停止生成按钮。
   - 当前知识范围提示。

#### 回答展示规则

- 支持 Markdown 基础格式，包括标题、列表、表格、引用和代码片段；需要进行安全过滤。
- 流式生成时保持页面稳定，用户主动向上滚动后不强制拉回底部。
- 答案正文中的引用标记必须与来源列表一一对应。
- 引用标记点击后打开来源预览，并定位到对应原文片段。
- 引用文档无权限、被停用或已删除时，不直接泄露内容；显示“来源当前不可访问”。
- 涉及日期、金额、资格条件和办理材料时，优先保留清晰的结构化表达。
- 回答结束前，复制、评价和重新生成操作保持不可用或弱化显示。

#### 生成阶段

前端可依次展示：

1. 正在理解问题。
2. 正在检索知识库。
3. 正在整理相关资料。
4. 正在生成回答。
5. 正在核对引用来源。
6. 回答完成。

实际阶段以后端事件为准，不应使用虚假进度百分比。

#### 停止生成

- 生成过程中发送按钮变为停止按钮。
- 用户停止后保留已经生成的内容，并标记“回答已停止”。
- 提供继续提问和重新生成入口。
- 停止操作失败时不阻塞页面，可提示请求可能仍在结束处理中。

#### 重新生成

- 默认基于相同问题、相同上下文和相同知识范围重新生成。
- 新回答完成前保留原回答，避免页面出现空白。
- 若保留多个回答版本，提供版本切换；如首期不保留，仅在确认后替换当前回答。
- 重新生成行为应进入操作或问答记录。

#### 评价与反馈

- 点赞后提供轻量成功反馈，可允许取消。
- 点踩后弹出原因选择：答案错误、内容不完整、来源不相关、内容已过期、表达不清晰、其他。
- “其他”或需要说明的类型提供补充文本框。
- 反馈提交后允许在短时间内修改，具体规则由后端确定。

#### 回答异常状态

| 状态 | 前端表现 | 用户操作 |
| --- | --- | --- |
| 未检索到内容 | 明确说明知识库暂无可靠依据 | 改写问题、切换知识库、提交反馈 |
| 生成失败 | 保留用户问题，显示失败原因概述 | 重试 |
| 网络中断 | 保留已生成内容，提示连接中断 | 继续生成或重试 |
| 内容被安全策略拦截 | 说明无法回答，不暴露内部规则 | 修改问题 |
| 引用获取失败 | 可展示回答，但明确标识引用未加载成功 | 重新加载引用 |
| 会话上下文过长 | 提示新建会话或系统已压缩上下文 | 新建会话 |

### 12.3 U03 历史对话页

#### 页面模块

- 页面标题和新建对话按钮。
- 关键词搜索。
- 时间范围筛选。
- 知识库筛选。
- 会话列表。
- 批量选择与删除（可作为后续增强）。
- 分页或滚动加载。

#### 会话列表字段

- 会话标题。
- 首个问题或最后一条消息摘要。
- 使用的知识库范围。
- 消息数量。
- 最后更新时间。
- 会话状态。

#### 功能规则

- 默认按最后更新时间倒序排列。
- 可按今天、最近 7 天、最近 30 天和更早分组。
- 搜索匹配标题和问题内容，结果中高亮关键词。
- 会话支持打开、重命名和删除。
- 删除前二次确认，并说明删除后是否可恢复。
- 默认仅展示当前用户本人的会话。

#### 页面状态

- 无历史记录：展示开始新对话的引导。
- 搜索无结果：展示清除条件和修改关键词入口。
- 列表加载失败：保留筛选条件并提供重试。

### 12.4 U04 文档来源预览

#### 展示形式

- 桌面端优先使用右侧抽屉，也可进入独立预览页。
- 移动端使用全屏页面或底部上拉面板。

#### 页面模块

- 文档名称和状态。
- 发布部门。
- 发布、更新、生效和失效日期。
- 所属知识库与分类。
- 当前引用的页码或章节。
- 引用原文及关键词高亮。
- 前后文内容。
- 文档目录或页码导航（解析结果支持时）。
- 下载原文件按钮（有权限时）。
- 返回回答位置按钮。

#### 功能规则

- 打开后自动定位到被引用片段。
- 同一答案存在多个引用时，支持上一条/下一条切换。
- 文档过期、已停用或为历史版本时显示明显状态提示。
- 无下载权限时隐藏或禁用下载入口，不影响合法的引用预览。
- 原文件暂不可预览时，至少展示系统解析出的引用文本和文档元数据。

### 12.5 U05 个人中心

#### 页面模块

- 头像。
- 姓名。
- 学号或工号。
- 登录账号。
- 用户类型。
- 所属院系或部门。
- 手机号和邮箱。
- 账号状态。
- 修改密码。
- 最近登录信息。
- 退出登录。

#### 功能规则

- 由统一认证同步的字段应为只读，并说明信息来源。
- 手机号和邮箱展示时按隐私策略脱敏。
- 修改密码需验证旧密码；统一认证账号跳转到对应平台。
- 退出登录需清理本地登录状态和敏感缓存。

### 12.6 U06 使用帮助页

- 系统能回答的内容范围。
- 推荐提问方式。
- 如何进行连续追问。
- 如何查看和判断引用来源。
- 系统不能处理的内容。
- 关于回答准确性的说明。
- 常见问题。
- 联系管理员或提交问题入口。

## 13. 管理后台详细需求

### 13.1 A01 管理概览

#### 页面目标

让管理员快速了解系统使用情况、知识库运行情况和需要处理的异常。

#### 指标卡片

- 知识库总数。
- 已入库文档数。
- 处理中任务数。
- 处理失败文档数。
- 用户总数。
- 今日活跃用户数。
- 今日问答量。
- 待处理反馈数。

指标根据当前管理员权限范围统计，并明确统计周期。

- 问答次数趋势。
- 活跃用户趋势。
- 文档上传与入库趋势。
- 回答满意度趋势。

#### 内容分析模块

- 高频问题。
- 高频检索关键词。
- 高频引用文档。
- 未命中问题。
- 负面反馈问题。

#### 待办与异常模块

- 解析失败文档。
- 长时间未完成的处理任务。
- 过期或即将过期文档。
- 待处理用户反馈。
- 服务异常状态。

- 数据部分加载失败时，其他成功模块继续展示。

### 13.2 A02 知识库列表

#### 筛选项

- 关键词：匹配名称和描述。
- 状态：启用、停用、处理中、异常。
- 管理部门。
- 可见范围。
- 创建人。
- 更新时间范围。

#### 列表字段

- 知识库名称。
- 描述摘要。
- 管理部门。
- 文档数量。
- 有效切片数量。
- 可见范围。
- 状态。
- 创建人。
- 更新时间。
- 操作。

#### 可用操作

- 新建。
- 查看详情。
- 编辑。
- 启用/停用。
- 配置权限。
- 检索测试。
- 重建索引。
- 删除。

#### 规则

- 停用前提示受影响的文档数和用户范围。
- 删除前必须检查是否包含文档、是否被权限规则或会话引用。
- 首期建议优先使用停用而非物理删除。
- 重建索引属于长耗时操作，提交后进入任务中心，不锁死当前页面。

### 13.3 A03 新建/编辑知识库

#### 基本字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 知识库名称 | 是 | 同一管理范围内不可重复，建议不超过 50 字 |
| 知识库标识 | 是/自动 | 用于系统识别，创建后是否可修改需明确 |
| 简介 | 是 | 说明知识范围与用途 |
| 管理部门 | 是 | 知识库责任部门 |
| 负责人 | 否 | 可选择一个或多个管理员 |
| 业务分类 | 否 | 用于筛选和推荐 |
| 可见范围 | 是 | 全校、指定角色、指定院系或指定用户 |
| 是否允许用户选择 | 是 | 决定是否出现在用户端知识库选择器 |
| 状态 | 是 | 启用或停用 |

#### 高级配置

- 默认切分方式。
- 默认切片长度。
- 默认重叠长度。
- 召回数量。
- 相似度阈值。
- 是否启用重排序。
- 回答提示规则或知识库说明。

高级参数默认收起，提供推荐默认值和风险提示。前端只负责配置展示，不规定具体算法。

#### 表单规则

- 离开存在未保存修改的页面时提示确认。
- 可见范围选择“指定对象”后必须至少选择一个对象。
- 编辑检索参数时，明确说明是否需要重建索引以及影响范围。
- 保存成功后返回详情页或保留在当前页面，行为需一致。

### 13.4 A04 知识库详情

#### 页面头部

- 名称、简介、状态。
- 管理部门和负责人。
- 创建与更新时间。
- 编辑、停用、上传文档、检索测试等主操作。

#### 标签页

1. 概览
   - 文档数、有效切片数、处理成功率、问答量、满意度。
   - 最近更新文档。
   - 最近异常任务。
2. 文档
   - 当前知识库内的文档列表与筛选。
3. 检索测试
   - 输入测试问题，查看召回片段和回答。
4. 权限范围
   - 查看并编辑角色、院系和用户范围。
5. 操作记录
   - 展示对知识库的创建、编辑、启停、上传和重建操作。

#### 检索测试要求

- 输入测试问题。
- 选择检索参数是否使用默认配置。
- 展示召回片段、文档、页码、相关度和排序。
- 展示基于当前召回结果生成的测试答案。
- 测试行为默认不进入普通用户会话历史，但应记录管理员操作日志或测试日志。
- 不向无权限管理员展示超出其范围的文档。

- 批量重新处理。
- 批量删除（仅在权限和产品策略允许时）。

批量任务完成后展示成功数、失败数和逐项失败原因，并允许导出失败清单。

#### 重复文档处理

系统通过文件哈希、文件名或内容相似度发现疑似重复时，前端需展示：

- 已存在文档名称和所属知识库。
- 已存在文档版本与更新时间。
- 可选操作：取消上传、仍然上传、作为新版本上传。
- 若管理员无权查看已存在文档，仅提示存在重复内容，不泄露文档详情。

### 13.6 A06 上传文档

#### 支持文件

具体格式和限制由后端配置返回，前端动态展示。首期建议支持：

- PDF。
- DOCX。
- TXT。
- Markdown。

XLSX、PPTX、图片等格式是否支持，应以实际解析能力为准，不在前端静态承诺。

#### 上传区域

- 拖拽上传。
- 文件选择。
- 支持格式说明。
- 单文件大小限制。
- 单次文件数量限制。
- 已选择文件列表。
- 单文件上传进度。
- 整体上传进度。
- 移除和重试操作。

#### 文档元数据

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 所属知识库 | 是 | 决定文档入库位置 |
| 显示名称 | 是 | 默认使用文件名，可修改 |
| 文档分类 | 是 | 规章制度、通知公告、办事指南等 |
| 发布部门 | 是 | 文档责任部门 |
| 文档编号 | 否 | 正式公文编号 |
| 发布日期 | 否 | 原文发布日期 |
| 生效日期 | 否 | 内容开始生效日期 |
| 失效日期 | 否 | 内容停止生效日期 |
| 标签 | 否 | 便于筛选与运营 |
| 可见范围 | 否 | 默认继承知识库，可进一步收窄 |
| 备注 | 否 | 仅管理员可见 |

#### 处理配置

- 自动判断是否需要 OCR。
- 手动强制 OCR。
- 切分方式。
- 切片长度。
- 重叠长度。
- 是否上传后立即处理。

配置默认继承知识库设置。普通知识库管理员可使用推荐配置，高级配置权限可按角色控制。

#### 上传规则

- 文件校验应尽可能在上传前完成。
- 某个文件不合格时不影响其他合格文件继续上传。
- 上传过程中关闭页面前给出提示；已进入后台处理的任务不受页面关闭影响。
- 文件上传完成后明确提示“上传完成，正在处理”，不得直接提示“入库成功”。
- 上传成功后提供“查看处理任务”“继续上传”“返回文档列表”入口。

## 14. 状态模型

### 14.1 文档处理状态

| 上传中 | 文件正在传输 | 查看进度、取消（支持时） |
| 上传失败 | 文件传输未完成 | 重试、移除 |

| 解析中 | 正在提取文本和结构 | 查看进度 |
| OCR 中 | 正在识别扫描内容 | 查看进度 |
| 切分中 | 正在生成文本切片 | 查看进度 |
| 向量化中 | 正在生成向量 | 查看进度 |
| 入库中 | 正在写入或更新检索索引 | 查看进度 |
| 已入库 | 文档可参与问答 | 预览、停用、重新处理 |
| 处理失败 | 某个处理阶段失败 | 查看原因、重试 |
| 已停用 | 文档不参与新检索 | 启用、查看 |
| 已过期 | 超过失效日期 | 更新、停用、查看 |

| --- | --- |

## 15. 全局交互状态

### 15.1 空状态

空状态应包含“发生了什么”和“下一步可以做什么”，不能只显示“暂无数据”。

| 场景 | 说明 | 建议操作 |
| --- | --- | --- |
| 无历史会话 | 用户尚未提问 | 展示推荐问题和新建对话 |
| 无可访问知识库 | 当前账号未配置权限 | 联系管理员 |
| 知识库无文档 | 管理员尚未上传内容 | 上传文档 |
| 搜索无结果 | 当前条件下没有匹配项 | 修改关键词或清除筛选 |
| 无处理任务 | 暂无异步任务 | 返回文档列表或上传文档 |
| 无反馈 | 当前没有待处理反馈 | 查看全部问答记录 |
| 无统计数据 | 当前周期没有数据 | 切换时间范围 |
| 问答未命中 | 未找到足够依据 | 改写问题、切换范围、反馈管理员 |

### 15.2 加载状态

- 页面首次加载优先使用与最终布局接近的骨架屏。
- 表格翻页和筛选使用局部加载，避免整个页面闪烁。
- 按钮提交后展示加载状态并阻止重复提交。
- AI 回答采用流式输出并展示真实阶段。
- 长耗时任务允许用户离开页面，在任务中心持续处理。
- 文档上传展示单文件进度和整体状态。
- 无法获得精确进度时只展示当前阶段，不显示虚假的百分比。

### 15.3 错误状态

| 错误类型 | 展示要求 | 恢复操作 |
| --- | --- | --- |
| 网络异常 | 简洁说明连接失败，保留用户输入 | 重试 |
| 登录失效 | 提示重新登录 | 登录后返回原页面 |
| 权限不足 | 不泄露受限内容 | 返回首页或申请权限 |
| 文件不支持 | 明确支持的格式 | 重新选择 |
| 文件过大 | 明确当前限制 | 重新选择 |
| 上传失败 | 标明失败文件 | 单个或批量重试 |
| 解析失败 | 展示失败阶段和可理解原因 | 重试或更换文件 |
| 生成失败 | 保留问题和已生成内容 | 重新生成 |
| 引用加载失败 | 回答内容仍可阅读，但标注风险 | 单独重试引用 |
| 部分数据失败 | 保留成功模块 | 重试失败模块 |

### 15.4 成功反馈

- 轻量操作使用页面提示或 Toast，例如复制成功、保存成功。
- 创建、上传、导入等重要操作提供清晰的结果页或结果摘要。
- 异步任务提交成功时，提示“任务已创建”，并提供查看任务入口。
- 批量操作必须展示成功数、失败数和失败原因。

### 15.5 确认与撤销

- 删除、停用、权限修改、覆盖文件、重建索引等操作必须说明影响范围。
- 可恢复的操作优先提供短时间撤销入口。
- 不可恢复的操作应使用明确的确认文案，必要时要求输入对象名称确认。
- 不使用含义模糊的“确定/取消”作为唯一信息，应在按钮上表达具体动作。

### 15.6 未保存离开

- 表单存在未保存内容时，关闭页面、返回或切换路由需要提示。
- 浏览器刷新或关闭窗口时使用浏览器允许的离开提醒机制。
- 已自动保存的草稿需明确显示最近保存时间。

## 16. 搜索、筛选、表格与分页规范

### 16.1 搜索

- 搜索框需说明搜索对象，例如“搜索文档名称、编号”。
- 输入法组合期间不得错误触发搜索。
- 支持清除关键词。
- 列表搜索可采用点击搜索或短延时自动搜索，全系统保持一致。
- 搜索结果中的关键词可高亮，但不得影响原文本复制。

### 16.2 筛选

- 常用筛选直接展示，高级筛选可折叠。
- 已生效筛选条件以标签形式展示，并支持单项清除。
- 提供“重置筛选”。
- 从概览页跳转到列表页时，应自动带入相应筛选条件。
- 返回列表时尽量保留上一次筛选、页码和滚动位置。

### 16.3 表格

- 固定关键识别列和操作列（宽屏情况下）。
- 长文本使用截断并支持悬停或展开查看。
- 状态使用文字加辅助标识，不能只依赖颜色。
- 无权限操作不展示；暂不可用操作禁用并说明原因。
- 批量选择后显示已选择数量和可用批量操作。

### 16.4 分页

- 管理列表默认使用分页。
- 支持每页数量选择时，返回列表需尽量保留用户选择。
- 删除当前页最后一项后自动回到有效页码。
- 普通用户会话列表可使用分页或连续加载，但需避免重复和丢失数据。

---

## 17. 表单与字段校验

### 17.1 通用规则

- 必填项明确标识。
- 校验错误尽量显示在字段附近，并在提交失败后定位到第一个错误字段。
- 输入限制同时说明允许格式和最大长度。
- 服务端返回的唯一性、权限或业务错误应映射到对应字段或表单顶部。
- 用户修正错误后及时清除旧提示。

### 17.2 文件校验

- 文件格式。
- 文件大小。
- 文件数量。
- 空文件或损坏文件。
- 加密或受密码保护文件。
- 疑似重复文件。
- 文件名包含异常字符。

### 17.3 日期校验

- 生效日期不得晚于失效日期。
- 文档已过失效日期时给出明显提醒。
- 所有日期时间按用户所在时区展示，并统一格式。

### 17.4 权限范围校验

- 指定院系、角色或用户时必须至少选择一个对象。
- 文档权限只能等于或小于其所属知识库权限，不能扩大访问范围。
- 移动文档至其他知识库时重新检查权限兼容性。

## 18. 通知与消息

### 18.1 站内通知场景

- 文档处理完成。
- 文档处理失败。
- 批量导入完成。
- 索引重建完成或失败。
- 用户反馈被处理。
- 系统维护公告。

### 18.2 通知规则

- 未读通知显示数量。
- 点击通知进入对应对象详情。
- 无权限或对象已删除时给出合理提示。
- 同一批量任务避免产生大量重复通知，应合并为一条任务结果。
- 是否同步发送邮件、短信或企业通信工具消息由后续配置决定。

## 19. 移动端与响应式要求

### 19.1 适配优先级

- 普通用户问答端：必须完整适配手机、平板和桌面端。
- 管理后台：桌面端优先；移动端保证查询、查看状态和基础处理可用。
- 文档批量上传、复杂权限配置、切片编辑等操作可提示使用桌面端，但不能出现页面完全不可访问。

### 19.2 建议断点

| 范围 | 建议宽度 |
| --- | --- |
| 小屏手机 | 小于 576px |
| 大屏手机 | 576px–767px |
| 平板 | 768px–1023px |
| 桌面端 | 1024px–1439px |
| 宽屏桌面 | 1440px 及以上 |

实际断点可由前端框架统一定义。

### 19.3 问答端移动规则

- 会话侧边栏改为抽屉。
- 输入区固定底部并适配安全区域。
- 软键盘弹出时确保输入框和发送按钮可见。
- 引用来源使用全屏详情或底部抽屉。
- 长答案支持快速回到底部。
- 复制、评价、重新生成可收纳到更多菜单。
- 表格型回答允许横向滚动，并提示可以滑动查看。
- 点击区域应满足移动端触控尺寸要求。

### 19.4 管理端移动规则

- 数据卡片从多列降为双列或单列。
- 表格切换为卡片列表，保留关键字段。
- 筛选条件收纳到全屏或侧边筛选面板。
- 行操作收纳到更多菜单。
- 批量操作仅在明确选中项目后出现。
- 图表需适配窄屏，复杂图表可提供数据列表视图。

## 20. 可访问性要求

- 所有功能可通过键盘完成基本操作。
- 明确展示当前焦点位置。
- 表单字段具有关联标签和错误提示。
- 图片、图标按钮提供可读的替代文本。
- 状态不能只通过颜色表达，需要文字或图标辅助。
- 弹窗打开后焦点进入弹窗，关闭后返回触发位置。
- 流式回答更新应避免让屏幕阅读器不断重复整段内容。
- 正文、按钮和状态标签需要满足基本对比度要求。
- 支持浏览器缩放后正常使用，避免关键功能被遮挡。

---

## 21. 安全与隐私要求

### 21.1 内容安全

- 前端渲染模型返回的 Markdown 或 HTML 时必须进行安全过滤。
- 不执行回答内容中包含的脚本、事件或不可信嵌入内容。
- 外部链接应明确标识，并根据安全策略打开。
- 引用预览只展示用户有权访问的内容。

### 21.2 账号安全

- 登录态失效后及时清理敏感页面数据。
- 密码输入和重置过程不记录明文。
- 高风险操作需要二次确认，必要时重新验证身份。
- 连续登录失败、账号锁定等策略由后端执行，前端展示对应状态。

### 21.3 隐私

- 用户列表中的手机号、邮箱和身份信息按权限脱敏。
- 问答内容可能包含个人信息，默认仅本人可见。
- 管理员查看完整问答需要专门权限和审计记录。
- 数据导出需要权限校验，并记录导出范围和操作者。

### 21.4 文件安全

- 前端不根据文件扩展名直接认定文件安全。
- 文件扫描和内容校验由后端执行，前端展示扫描状态。
- 发现风险文件时禁止进入后续解析流程，并提供管理员可理解的提示。

---

## 22. 非功能需求

### 22.1 性能体验

- 页面应优先展示框架和可交互内容，避免长时间白屏。
- 大型列表必须分页或虚拟加载，避免一次渲染过多数据。
- 流式回答应平滑展示，避免高频更新导致页面卡顿。
- 文档预览较大时按页或按需加载。
- 搜索和筛选请求需防止重复提交与响应乱序覆盖。

### 22.2 稳定性

- 网络短暂中断后应尽可能恢复列表、上传或回答状态。
- 异步任务状态以后端为准，刷新页面后仍可继续查看。
- 页面刷新不应导致已经成功提交的任务重复创建。
- 重复点击发送、上传或保存不得产生重复业务数据。

### 22.3 兼容性

- 支持学校规定的主流现代浏览器。
- 建议优先支持近两个主要版本的 Chrome、Edge、Safari 和 Firefox。
- 如学校存在旧浏览器环境，应在开发前单独确认兼容范围。

### 22.4 可维护性

- 页面状态、角色权限、文档状态和任务状态使用统一枚举与文案。
- 相同的搜索、筛选、分页、确认弹窗和上传体验应复用统一规范。
- 后端新增状态时，前端应有未知状态的安全兜底展示。

## 24. 前后端状态同步要求

- AI 回答需支持流式消息、完成消息、错误消息和引用完成消息。

- 文档处理和批量任务支持轮询、服务端推送或手动刷新；具体方式由技术方案确定。
- 前端不得仅依靠本地状态判断文档已入库或用户已禁用。
- 所有列表请求应返回总数、分页信息和当前有效筛选数据。
- 所有高风险操作返回明确的成功、部分成功或失败结果。
- 接口错误需包含稳定的错误码和适合展示或映射的错误信息。
- 后端返回用户不可见的技术堆栈时，前端不得直接展示给普通用户。

## 26. 核心验收标准

### 26.1 登录与权限

1. 正常用户可以成功登录并进入正确首页。
2. 禁用用户不能登录，并看到明确提示。
3. 普通用户不能访问管理页面或管理接口。
4. 不同管理员只能看到其权限范围内的知识库、文档和数据。
5. 登录过期后重新登录可以返回原访问页面，前提是仍有权限。

### 26.2 智能问答

1. 用户可以发送合法问题并看到检索和生成状态。
2. 回答可以流式展示，且生成期间可停止。
3. 完成的回答可以复制、评价和重新生成。
4. 答案引用编号与来源列表正确对应。
5. 点击引用可定位到正确文档和原文片段。
6. 未检索到可靠资料时不展示虚假引用，并提供下一步建议。
7. 网络失败或生成失败后保留用户问题，并允许重试。
8. 连续追问能够保留同一会话上下文。

### 26.3 历史会话

1. 用户可以查看、搜索和打开自己的历史会话。
2. 用户可以重命名和删除会话。
3. 删除操作需要确认，结果及时反馈。
4. 用户不能查看其他用户的历史会话。

### 26.4 知识库管理

1. 有权限管理员可以创建、编辑、启用和停用知识库。
2. 停用知识库后普通用户无法基于其发起新检索。
3. 可见范围配置可以正确限制用户访问。
4. 高级配置修改时能说明是否需要重建索引。
5. 知识库详情能够展示文档、统计、权限和操作记录。

### 26.5 文档管理

1. 管理员可以上传符合要求的文件并填写元数据。
2. 不符合格式、大小或数量要求的文件在上传前得到提示。
3. 上传完成与入库完成被明确区分。
4. 管理员可以查看解析、切分、向量化和入库阶段。
5. 处理失败时可以查看失败原因并重试。
6. 已停用文档不再参与新的问答检索。
7. 批量操作能够展示成功、失败和失败原因。
8. 无下载权限的用户不能通过页面或直接请求获取原文件。

### 26.6 用户管理

1. 有权限管理员可以搜索、筛选、新建和编辑用户。
2. 管理员可以启用、禁用和重置普通用户账号。
3. 批量导入在正式执行前能够展示校验结果。
4. 管理员角色分配仅对超级管理员开放。
5. 高风险操作有二次确认并记录日志。

### 26.7 反馈与分析

1. 用户可以提交点赞和点踩反馈。
2. 点踩可以选择原因并填写补充说明。
3. 管理员可以查询、领取或处理反馈。
4. 解决反馈时必须填写处理结论。
5. 概览和问答记录中的统计只包含管理员有权查看的数据。

### 26.8 响应式与异常状态

1. 手机端可完整完成登录、提问、查看回答和引用、继续追问。
2. 软键盘弹出时输入框和发送按钮可用。
3. 核心页面具备加载、空、错误和无权限状态。
4. 表格在小屏设备上能够以卡片或横向适配方式使用。
5. 页面刷新后不会重复提交已经创建的问答或处理任务。

## 28. 原型设计交付要求

后续使用 Stitch 生成原型时，建议至少覆盖以下页面和关键状态：

1. 登录页：默认、字段错误、登录失败。
2. 问答首页：有推荐内容、无可访问知识库。
3. 对话详情：检索中、生成中、回答完成、无答案、生成失败。
4. 引用来源：抽屉预览、文档不可访问、文档已过期。
5. 历史会话：正常列表、搜索无结果、无历史记录。
6. 管理概览：正常数据、无数据、部分模块失败。
7. 知识库列表与新建/编辑表单。
8. 知识库详情：概览、文档、检索测试、权限范围。
9. 文档列表：多状态、批量选择、筛选无结果。
10. 上传文档：待上传、上传中、部分失败、进入后台处理。
11. 文档详情：已入库、处理中、处理失败、已停用。
12. 任务中心：执行中、部分成功、失败。
13. 用户管理：列表、新建/编辑、批量导入校验、禁用确认。
14. 问答记录详情和反馈处理。
15. 系统设置和操作日志。
16. 普通用户端手机布局。
17. 管理端窄屏列表与筛选布局。

原型中的每个核心页面应表现：

- 页面入口与返回路径。
- 主操作和次操作。
- 表单校验。
- 加载状态。
- 空状态。
- 错误状态。
- 无权限状态。
- 危险操作确认。
- 操作成功反馈。

## 29. 待产品与技术确认事项

以下事项不阻塞首版原型，但需要在开发前确认：

1. 是否接入学校统一身份认证，是否保留本地账号登录。
2. 普通用户能否主动选择知识库，还是由系统自动检索所有有权内容。
3. 首期支持的文件格式、单文件大小和单次上传数量。
4. 扫描 PDF 是否默认自动 OCR，OCR 失败如何处理。
5. 文档是否需要正式版本管理，以及新旧版本切换规则。
6. 文档失效后是自动停止检索还是仅提示管理员。
7. 知识库和文档权限需要支持到角色、院系还是具体用户。
8. 管理员是否可以查看用户完整问答内容，审批和审计要求是什么。
9. 回答是否允许使用模型通用知识补充；如允许，应如何区分知识库内容与通用内容。
10. 引用原文件是否允许下载，是否需要水印。
11. 会话、问答记录和操作日志的保留周期。
12. 删除操作采用逻辑删除还是物理删除，是否提供恢复能力。
13. 是否需要站内通知，以及是否接入邮件、短信或企业通信工具。
14. 是否需要敏感问题拦截、敏感词管理和人工审核机制。
15. 是否需要多校区、多学院或多租户隔离。
16. 系统的目标并发量、文档规模和可接受响应时间。

在以上事项尚未确定时，原型建议采用本文中给出的默认方案，并将相关能力设计为可配置或可扩展。

## 30. 默认产品决策摘要

为便于原型和首期开发，在没有额外说明时采用以下默认决策：

- 系统分为普通用户问答端和管理后台。
- 管理员同时拥有普通用户问答能力。
- 回答必须优先基于用户有权访问的知识库。
- 无可靠检索依据时明确拒绝给出确定性答案。
- 答案正文中的引用标记与原文来源一一对应。
- 文件上传成功后继续异步处理，只有“已入库”文档才能参与检索。
- 知识库和文档优先使用停用，不直接物理删除。
- 文档权限默认继承知识库权限，只允许进一步收窄。
- 普通用户端移动优先，管理后台桌面优先并提供基础移动适配。
- 所有长耗时任务进入任务中心，用户可以离开当前页面。
- 所有高风险操作均需二次确认并记录审计日志。
